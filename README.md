# 📱 Generador de QR

Convertí cualquier texto o URL en un código QR descargable. HTML/CSS/JS puro
— usa la API pública gratuita [api.qrserver.com](https://goqr.me/api/) para
generar la imagen, sin backend propio ni librerías que instalar.

Gratis para usar, modificar y regalar.

## Usar

Abrí `index.html` (necesita conexión a internet para generar el QR).
