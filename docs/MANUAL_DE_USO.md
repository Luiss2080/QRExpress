# Manual de Uso: QR Pro Ultimate

Bienvenido a la documentación oficial de **QR Pro Ultimate**, la herramienta de nivel empresarial para generación de códigos QR, procesamientos masivos y escaneo inteligente.

## 1. Generador Individual

La herramienta principal te permite crear códigos QR dinámicos y estáticos al instante.

### Pasos:
1. Abre la pestaña **Individual**.
2. **Selecciona el Tipo**:
   - *URL*: Para páginas web estándar.
   - *Redes Sociales*: Plantillas pre-diseñadas (YouTube, Instagram).
   - *Correo/Ubicación*: Funciones nativas de móviles.
3. **Ingresa los Datos**: Escribe tu URL en el campo principal. Verás que la vista previa se actualiza automáticamente.
4. **Personalización Visual**: Usa los selectores de color para adaptar el QR a la identidad visual de tu marca.
5. **Exportación**: Haz clic en *Descargar PNG* para obtener la imagen en alta calidad lista para impresión o redes sociales.

## 2. Generación Masiva (CSV)

Diseñado para procesar cientos de QRs sin colgar tu computadora (procesamiento asíncrono).

### Pasos:
1. Dirígete a la pestaña **Generación Masiva**.
2. Asegúrate de tener un archivo `.csv` con tus URLs/textos (un elemento por línea).
3. Sube el archivo arrastrándolo o haciendo clic en el botón de subida.
4. Espera a que el Web Worker termine. Obtendrás un archivo `.zip` comprimido con todas las imágenes numeradas.

## 3. Escáner Web
¿Necesitas leer un QR físico? Tu PC o móvil sirve como escáner nativo.

### Pasos:
1. Ve a la pestaña **Escáner Web**.
2. Otorga los permisos de cámara que te pedirá el navegador.
3. Apunta tu lente al código QR; una vez decodificado, el resultado aparecerá en pantalla.

---

> [!TIP]
> **Modo Oscuro**: La aplicación respeta el tema de tu sistema operativo para no cansar tu vista en entornos de baja iluminación.
